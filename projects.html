  • Tirra : Encrypted Notebook written in Rust.

    • A multi-platform desktop application to write encrypted notes, written in Rust.
    Features:

    • Browse, read, and edit text entries stored in an encrypted SQLite database
    • Open file format (SQLite)
    • On-the-fly encryption powered by the SQLite3 encryption extension tirravfs

  • tirra-vfs : on-the-fly encryption for SQLite, written in Rust.

    • tirravfs is a SQLite3 extension implementing a VFS shim that brings on-the-fly encryption to SQLite3 databases. Database files remain encrypted at rest, with pages decrypted on read and re-encrypted on write.

    This extension is used in the encrypted notebook project: Tirra

  • tirrage : file encryption in Rust using Age protocol.

    • A Rust implementation of the Age v1 file encryption format, supporting scrypt-based passphrase encryption.

  • proc/maps parser :

    • A lightweight library, written in C, to parse Linux's /proc/[pid]/maps file, which contains the memory map of a process
